# 3D Tilt Simulator (Node.js & WebSocket Edition)

Node.js環境で2D物理演算および3D透過投影（透過3Dキューブレンダリング）を行い、WebSocketを介してブラウザへリアルタイムに低遅延配信する、サーバーサイド・レンダリング型の自律シミュレーターゲームです。

元のフロントエンド完結型システムを、スケーラビリティとロジック隠蔽（インテリジェンス防衛）を考慮した「演算・描画サーバー ⇄ 表示クライアント」の分散型構造へとリファクタリングしました。

## 🚀 特徴 & 技術スタック

- **物理演算（2D Engine）**: `Tiny2D.js` をNode.jsのサーバーサイド・ループ内で駆動。剛体の挙動、重力ベクトルの動的変化を毎フレーム高速にマトリクス計算します。
- **3D 投影演算**: クォータニオンや行列回転の思想に基づき、3次元座標（XYZ）を2次元のCanvas座標へリアルタイムに透視投影（パースペクティブ射影）。面の法線ベクトルと光源（Light Vector）の内積からシェーディング（陰影）を動的計算しています。
- **リアルタイム通信**: `Socket.IO` を採用。クライアント側のキー入力を検知してサーバーの重力場にフィードバックし、サーバーサイドで描画したCanvasバッファ（Base64 DataURL）を全クライアントへ秒間約40フレームで高速ブロードキャストします。
- **バックエンド描画**: `node-canvas` を使用し、ヘッドレス環境（C++ネイティブバインディング）でのグラフィックレンダリングを実現。

## 🛠️ 必要環境

- Node.js (v22.17.0 以上推奨)
- npm (Node Package Manager)

依存パッケージのインストールnode-canvas のコンパイルに必要なネイティブライブラリを含め、一括インポートします。

🏃 実行方法
開発モード（サーバー起動）
Bash
npm run dev
サーバーがスタックすると、ターミナルに以下のアドレスが表示されます。サーバーが起動しました。URL: http://localhost:3000

ブラウザを開き、http://localhost:3000 にアクセスすることでシミュレーターが駆動します。

🎮 操作方法
ブラウザのウインドウ上で以下のキーを操作します。

← / → (矢印キー) : 3Dステージを左右に傾けます（Y軸回転・重力場の変更）

↑ / ↓ (矢印キー) : 3Dステージを前後に傾けます（X軸回転・重力場の変更）

ステージの傾きに応じて内部の重力ベクトルが動的に推移し、物理エンジンによって球体が迷路（Cube群）を滑り落ちるシミュレーションが行われます。
